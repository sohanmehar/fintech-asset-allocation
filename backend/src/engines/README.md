# CapitalGuard Engines Directory (Phase 2+)

This folder will house the core computation modules in future phases:

- `risk.engine.ts`: Calculates portfolio volatility, VaR, Sharpe ratio, max drawdown, and policy breaches.
- `optimization.engine.ts`: Mean-Variance / Sharpe / Min-Volatility portfolio optimization algorithms.
- `scenario.engine.ts`: Stress testing under historical crash scenarios, interest rate shocks, and geopolitical events.
